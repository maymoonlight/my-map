# 📍 사업장 마커 생성 및 스타일 결정 로직 순서도

본 문서는 엑셀 데이터를 기반으로 지도의 마커(색상, 투명도, 아이콘)를 결정하는 핵심 알고리즘을 정의합니다.

## 1. 개요
- **목적**: 방문 회차 및 업체 특성에 따른 시각적 차별화
- **핵심 변수**: 
    - `v_count`: 방문회차 (0~9)
    - `quick_pass`: 퀵패스 여부 (문자열)
    - `monitoring`: 모니터링 여부 (문자열)
    - `d_count`: 재해발생건수 (정수)

---

## 2. 시각화 로직 순서도

```mermaid
graph TD
    %% 시작점
    START([데이터 로우 읽기]) --> VALID{위도/경도 존재?}
    
    %% 데이터 검증
    VALID -- No --> SKIP[건너뛰기]
    VALID -- Yes --> PRE[데이터 전처리 및 변수 선언]
    
    %% 전처리 구간
    PRE --> VARS[is_quick / is_mon / has_accident 정의]
    VARS --> CATEGORY{방문 상태 분류}

    %% [A] 특수/제외 케이스
    CATEGORY -- "일반장소" --> STYLE_A[Red / info 아이콘]
    CATEGORY -- "9회차 (제외)" --> STYLE_B[Lightgray / 흐리게 0.4]
    CATEGORY -- "0회차 (방문전)" --> STYLE_C[Gray / 업종별 아이콘]

    %% [D] 방문 중 상세 로직 (1~8회차)
    CATEGORY -- "1~8회차 (방문중)" --> D_OPACITY[투명도 결정: is_quick ? 1.0 : 0.6]
    
    D_OPACITY --> D_COLOR{재해 발생 여부?}
    D_COLOR -- Yes --> RED_PIN[핀 색상: Red]
    D_COLOR -- No --> SECTOR{업종 구분}
    
    %% 업종별 색상 분기
    SECTOR -- "특화" --> PURPLE[is_mon ? Purple : Darkpurple]
    SECTOR -- "제조" --> BLUE[is_mon ? Blue : Darkblue]
    SECTOR -- "기타" --> GREEN[is_mon ? Green : Darkgreen]

    %% 아이콘 결정
    PURPLE & BLUE --> BATT_5[배터리 아이콘: 5단계 적용]
    GREEN --> BATT_3[배터리 아이콘: 3단계 적용]
    
    %% 최종 조립
    RED_PIN & BATT_5 & BATT_3 --> ICON_COL[아이콘 내부색: has_accident ? Red : White]
    STYLE_A & STYLE_B & STYLE_C & ICON_COL --> POPUP[팝업 데이터 정제: extra_info / phone_link]
    
    POPUP --> RENDER[folium.Marker 생성 및 지도 추가]
    RENDER --> END([다음 데이터로 이동])

    %% 스타일 정의
    style STYLE_A fill:#f96,stroke:#333
    style RED_PIN fill:#ff9999,stroke:#f00
    style PURPLE fill:#e1d5e7,stroke:#9673a6
    style BLUE fill:#dae8fc,stroke:#6c8ebf
    style GREEN fill:#d5e8d4,stroke:#82b366
```

## 3. 주요 방어적 코드 (Defensive Code)
나중에 코드를 수정할 때 참고해야 할 핵심 구문입니다.

1. **문자열 포함 확인 (`in`)**: 엑셀 입력 오류 방지
   - `is_mon = '모니터링' in monitoring.strip()`
2. **팝업 쉼표 정제**: 정보가 없을 때 깔끔하게 표시
   - `extra_info = f"{q_display}, {m_display_text}".strip(", ")`
3. **클릭 방지 링크**: 정보가 없을 때 오작동 방지
   - `phone_link = f"tel:{phone}" if phone != '정보없음' else "javascript:void(0);"`
